# linux-namespaces

|  # | Namespace | Purpose                                  |
| -: | --------- | ---------------------------------------- |
|  1 | `mnt`     | Mount and filesystem isolation           |
|  2 | `pid`     | Process ID isolation                     |
|  3 | `net`     | Network interfaces, routing, ports, etc. |
|  4 | `uts`     | Hostname and domain name isolation       |
|  5 | `ipc`     | System V IPC and POSIX message queues    |
|  6 | `user`    | User and group ID isolation              |
|  7 | `cgroup`  | Cgroup hierarchy isolation               |
|  8 | `time`    | System and monotonic clock isolation     |
